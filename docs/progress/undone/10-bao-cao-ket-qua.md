# Đưa kết quả vào báo cáo

**Ưu tiên:** trung bình (sau khi có kết quả MATLAB) · **Phụ trách:** biên tập, cùng người làm mô phỏng

## Việc cần làm

- [ ] Viết phần kết quả mô phỏng vào báo cáo LaTeX (`report/`), nối tiếp chương 06 "Kế hoạch mô phỏng":
  - PV-01..04 (bảng + đồ thị I–V, P–V).
  - ARR-01..04 (bảng 16 trạng thái × 9 ca, xếp hạng cấu hình, P–V của SP / TCT / BL / trạng thái tốt nhất).
  - Ứng suất công tắc làm cơ sở chọn linh kiện.
  - ARR-05: điện năng theo thuật toán, so với oracle.
  - Quá độ đóng/cắt.
  - DES: tăng thêm so với 4 công tắc, và chọn theo EI so với chọn theo công suất.
- [ ] Nêu rõ giả thiết: thông số tấm, kiểu bộ sạc, 25 °C, công tắc lý tưởng, tỉ lệ diện tích bóng.
- [ ] Sau thực nghiệm: thêm chương so sánh mô phỏng với đo đạc ([undone/07](07-thuc-nghiem.md)).
- [ ] Chương PCB: schematic, layout, BOM, kết quả kiểm tra từng khối ([undone/05](05-thiet-ke-pcb.md)).
- [ ] Build PDF (MiKTeX portable, `pdflatex` 3 lần) rồi nộp theo mốc trên LMS.
