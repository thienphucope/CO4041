## B. Đã sắp xếp lại

### 1. Proposal GĐ1 gồm những gì?
- **Thiết kế BMS 12V**: SoC, nhiệt độ, cân bằng cell, mạch bảo vệ.
- **Mô phỏng chức năng trên Proteus** trước khi làm phần cứng.
- **Mô phỏng tấm pin (PV)**.
- **Tìm hiểu thuật toán PV array configuration** (cấu hình/sắp xếp dàn pin).
- Proposal **chưa đi vào chi tiết** — chỉ nêu **phương pháp tổng quan, kế hoạch, phân chia nhiệm vụ**.

### 2. Mốc 2 tuần & deliverable
- Là **báo cáo tiến độ**, nộp trên **LMS**. **Không cần** slide / thuyết trình.

### 3. Hạn chót & nơi nộp
- **Xem hạn trên LMS** (nộp trên LMS).

### 4. Tài liệu tham khảo
- Thầy cung cấp một số tài liệu; **ngoài ra nhóm phải tự tìm thêm** cho proposal.
- 3 tài liệu thầy cung cấp (đã lưu ở [`../references/`](../references/), xem [`references.md`](../references/references.md)):
  1. *A new model for a photovoltaic panel using Proteus software tool under arbitrary environmental conditions* → mô phỏng PV trên Proteus.
  2. *Hybrid battery management system using the internet of things* → BMS + IoT.
  3. *SIMULATION OF RECONFIGURATION SYSTEM USING MATLAB - SIMULINK ENVIRONMENT* → PV array reconfiguration.

### Chốt lại (ảnh hưởng kế hoạch)
- **Công cụ mô phỏng: Proteus** (thầy chốt) — cho cả BMS lẫn tấm pin. (Trước nhóm đoán MATLAB/pvlib; MATLAB-Simulink chỉ còn cho phần *reconfiguration* theo ref thầy đưa.)
- **Deliverable nhẹ hơn dự đoán**: chỉ **báo cáo tiến độ trên LMS**, **không** slide/thuyết trình.
- **Mức độ proposal**: tổng quan (phương pháp + kế hoạch + phân việc), **chưa cần chi tiết** → chưa lo schematic/PCB ở mốc này.
- **Hạn**: kiểm tra LMS lấy ngày chính xác.
- **Tài liệu**: 3 ref thầy đưa đã lưu; còn phải **tự tìm thêm**.
